# KostholdsGPT

## For å bruke nettsiden må du laste ned og hoste ollama.

### Fohåndsbehov
Node.js \
Ollama 

#### Steg 1:
last ned Ollama fra nettsiden demmes. \
https://ollama.com/

#### Sted 2:
åpne ollama og logg inn

#### Steg 3:
Åpne terminal og run: \
ollama signin \
ollama pull gpt-oss:120b-cloud 

# Last ned repo


## Metode 1: Clone repo fra terminal
git clone [<repo-url>](https://github.com/noxaur/KostholdsGPT) \
cd Backend \
npm install 


## Metode 2: 

#### Steg 1:
Last ned repoet fra github sin nettside.

#### Steg 2: 
Finn det repoet i finder og høyreklikk på Backend, se ned og trykk på "New terminal at folder".

#### Steg 3:
Skriv inn: \
npm install
